# LSTM-for-Timeseries

Thid project shows an application on real data of the LSTM model for timeseries. The timeseries is made of running metrics and parameters recorded during a Marathon by a Garmin device. The model taken mostly from the pytorch documentation (https://docs.pytorch.org/docs/stable/generated/torch.nn.LSTM.html). Useful suggestions and code snippets are taken from "Intuitive understanding of recurrent neural networks" by Adaloglou Nikolas and Karagiannakos Sergios (https://theaisummer.com/gru/) and "LSTM for Time Series Prediction in PyTorch" by Adrian Tam (https://machinelearningmastery.com/lstm-for-time-series-prediction-in-pytorch/).
